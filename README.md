### 🚀 Projetos em Destaque

#### 🏦 EXATUS — SaaS de Inteligência e Conciliação Financeira B2B
> Plataforma completa de gestão contábil e conciliação bancária multi-tenant com separação estrita de regimes contábeis (DRE por Competência vs. DFC por Caixa).
- **Back-End:** FastAPI, SQLAlchemy 2.0, PostgreSQL, migrações com Alembic, segurança JWT/RBAC.
- **Processamento de Dados:** Ingestão flexível de extratos bancários (OFX) e planilhas financeiras dinâmicas (XLSX/CSV) com regras automáticas de autoclassificação.
- **Front-End:** React 19, TypeScript, Tailwind CSS e Recharts com exportação executiva de relatórios.
- **Status:** Validado e em testes de homologação com clientes reais.

#### 📦 Módulo de Auditoria de Estoque — SaaS Multi-Tenant
> Solução corporativa desenvolvida para conciliação física de inventário e cruzamento analítico de dados operacionais.
- **Arquitetura:** FastAPI + PostgreSQL + SQLAlchemy.
- **Mecanismo:** Análise automatizada de planilhas via Pandas para detecção imediata de divergências e relatórios de furos de estoque.
- **Segurança:** Autenticação por token e controle de acessos segregado.

#### 🌐 Soluções Web & Portfólios
